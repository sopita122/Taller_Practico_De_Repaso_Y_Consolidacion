El objetivo del proyecto es repasar y consolidar conceptos fundamentales de programación en C++, especialmente aquellos relacionados con el manejo de memoria y el funcionamiento de diferentes estructuras y técnicas de bajo nivel.
El programa reúne tres retos principales:
    - **Recursividad:** se utiliza una función que se llama a sí misma para calcular una suma acumulada, utilizando un caso base para detener las llamadas y evitar un Stack Overflow.
    - **Búsqueda secuencial:** se recorre un arreglo de forma indexada para encontrar un valor determinado. Cuando el valor es encontrado, se utiliza `break` para finalizar el recorrido.
    - **Punteros e intercambio de valores:** se utilizan punteros, pasaje por dirección y desreferenciación para modificar directamente los valores de dos variables y realizar un intercambio entre ellas.
Además, el proyecto permite observar las direcciones de memoria mediante el operador `&` y trabajar con conceptos relacionados con la memoria RAM, los arreglos contiguos y las direcciones hexadecimales.
